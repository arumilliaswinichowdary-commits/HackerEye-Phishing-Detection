## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- Random Forest Machine Learning

## Features
- User Registration
- User Login

- Phishing Website Detection
- MySQL Database Integration
- Prediction History Storage

User → Login → URL Input → Feature Extraction → Random Forest Model → Prediction → MySQL Storage
